Setup Guide

Connect SwarmSpace to Claude

Add 13 intelligence tools to Claude in under two minutes. SwarmSpace gives Claude the ability to research, analyze, and synthesize information from across the web.

Setup: Claude.ai

  1. Open Claude.ai and go to Settings → Integrations (or MCP Servers)
  2. Click Add MCP Server
  3. Enter the server URL: https://swarmspace-mcp-server.orbitalai.workers.dev/mcp
  4. Click Connect — you will be redirected to swarmspace.app to sign in
  5. Sign in with your Google account and approve the permissions
  6. Return to Claude — SwarmSpace tools will appear in your tool list

Setup: Claude Code (CLI)

Add this to your claude_desktop_config.json or .claude/mcp.json. OAuth authentication runs automatically on first use.

{
  "mcpServers": {
    "swarmspace": {
      "url": "https://swarmspace-mcp-server.orbitalai.workers.dev/mcp"
    }
  }
}

Troubleshooting

Symptom Cause Fix
"Authorization required" or 401 on first connect OAuth not yet completed Click the authorization link that appears in Claude and sign in at swarmspace.app
"CONSENT_REQUIRED" error OAuth scope not approved Disconnect the server in Claude settings, then reconnect and re-approve
403 Forbidden Expired session or plan mismatch Check your plan at swarmspace.app/dashboard; disconnect and reconnect to refresh your session
Tool returns empty results Query too broad or upstream timeout Rephrase the query more specifically and retry once
OAuth redirect loop Browser blocking third-party cookies Allow cookies for swarmspace-mcp-server.orbitalai.workers.dev in your browser settings
Server not appearing in Claude URL entered incorrectly Confirm the URL ends in /mcp: https://swarmspace-mcp-server.orbitalai.workers.dev/mcp

Still stuck? Email marcyap@orbitalai.net with a description of the issue and which Claude surface you're using.
